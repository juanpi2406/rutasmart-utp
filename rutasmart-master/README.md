# rutasmart-master

Frontend Angular oficial de RutaSmart.

## Ejecutar

```bat
cd C:\Users\Teseo OS\Desktop\rutasmart\rutasmart-master
npm start
```

URL: `http://localhost:4200`

## Backend requerido

El login y el envío de incidencias consumen:

`http://localhost:8080/api`

Levanta primero `rutasmartservice-master`.

## Compilar

```bat
npm run build
```
